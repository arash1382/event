# دبیرخانه مرکزی راهبری و برگزاری رویدادهای ایران‌مال

**Iran Mall — Central Event Governance Secretariat**
سامانه مرجع ثبت، ارزیابی، تصویب، اجرا و پایش تمامی رویدادهای ایران‌مال.

> این پروژه یک وب‌سایت ثبت‌نام رویداد **نیست**. این یک **پلتفرم راهبری و کنترل** است: مرجع واحدی که همه رویدادها را از ایده تا اختتام مدیریت می‌کند و هیچ رویدادی بدون عبور از **۱۴ گیت کنترلی** و بدون **Event ID** اجازه اجرا نمی‌گیرد.

---

## اجرا

سامانه از ES Modules استفاده می‌کند، بنابراین باید از طریق یک وب‌سرور (نه `file://`) اجرا شود:

```bash
python3 -m http.server 8099 --bind 0.0.0.0
# سپس http://localhost:8099/
```

بدون هیچ مرحله build، نصب پکیج یا وابستگی خارجی اجرا می‌شود (Vanilla ES Modules).

## قابلیت‌ها

- **RTL کامل** با تقویم جلالی بومی (بدون کتابخانه): جابه‌جایی ماه، روز جاری، تعطیلات، انتقال خودکار روزهای بزرگ‌تر از طول ماه به ماه بعد.
- **جست‌وجوی سراسری** (Ctrl/⌘ + K) روی گیت‌ها، پرونده‌ها، مجوزها، مهمانان، واحدها و مراحل، با پرش مستقیم به پرونده.
- **کشوی جزئیات** برای هر گیت، رویداد، مجوز و مهمان با چک‌لیست، مستندات الزامی و معیارهای رد.
- **حالت ارائه به هیئت‌مدیره** (بزرگ‌نمایی کل سامانه) و **خروجی چاپی A3 افقی** با سرصفحه رسمی.
- **صرفه‌جویی در پویانمایی** (`prefers-reduced-motion`) و پرش به محتوا برای دسترس‌پذیری.

## اصول پایه پیاده‌شده در منطق سامانه

1. هیچ رویدادی بدون Event ID اجرا نمی‌شود.
2. تأیید شفاهی معتبر نیست.
3. هر رویداد مالک مشخص دارد.
4. مجوزها باید تعیین تکلیف شوند.
5. برنامه بازاریابی الزامی است.
6. HSE و حراست حق توقف رویداد غیرمنطبق را دارند.
7. پرونده بدون گزارش نهایی بسته نمی‌شود.
